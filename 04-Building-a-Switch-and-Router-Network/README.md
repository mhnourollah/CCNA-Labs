# Building a Switch and Router Network

## Objective

Build a small network consisting of a router, switch, and two PCs. Configure IPv4 addressing, basic device security, and verify end-to-end connectivity between different networks.

## Skills Practiced

- Router Configuration
- Switch Configuration
- Interface Addressing
- Device Security
- Remote Management
- Routing Verification
- End-to-End Connectivity Testing

## Key Commands

```cisco
hostname R1
hostname S1
enable secret class
service password-encryption
banner motd
interface g0/0/0
interface g0/0/1
ip address
no shutdown
show ip interface brief
show ip route
ping
```

## What I Learned

This lab demonstrated how routers connect multiple networks and enable communication between devices on different subnets. I learned how to configure router interfaces, assign IP addresses, secure network devices, verify routing information, and troubleshoot connectivity using show commands and ping tests.
