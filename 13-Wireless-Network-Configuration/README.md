# Configure a Wireless Network

## Objective

Configure a wireless router, secure a wireless network using WPA2, enable DHCP services, and connect client devices to a WLAN.

## Skills Practiced

- Wireless Router Configuration
- SSID Configuration
- WPA2 Wireless Security
- AES Encryption
- DHCP Configuration
- Wireless Client Connectivity
- Access Point Configuration
- WLAN Troubleshooting

## Key Commands and Settings

```text
SSID Configuration
WPA2-Personal Security
AES Encryption
DHCP Server Setup
Router IP Configuration
Default Gateway Configuration
Wireless Client Association
```

## What I Learned

This lab demonstrated how to configure and secure a wireless local area network (WLAN). I learned how to configure an SSID, implement WPA2 security with AES encryption, configure DHCP services for wireless clients, connect devices to a wireless network, and extend wireless coverage using an access point.
