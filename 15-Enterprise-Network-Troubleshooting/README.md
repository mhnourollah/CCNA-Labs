# Enterprise Network Troubleshooting

## Objective

Troubleshoot and restore functionality in an enterprise network environment involving switching, routing, DHCP, NAT, OSPF, IPv6, EtherChannel, VLANs, and WAN connectivity.

## Skills Practiced

- Network Troubleshooting Methodology
- VLAN Verification
- Port Security Troubleshooting
- EtherChannel Troubleshooting
- Trunk Verification
- DHCP Troubleshooting
- OSPF Troubleshooting
- IPv4 Routing Verification
- IPv6 Routing Verification
- NAT Troubleshooting
- WAN Connectivity Testing
- End-to-End Connectivity Validation

## Key Commands

```cisco
show vlan brief
show port-security
show etherchannel summary
show interfaces trunk

show ip route
show ip ospf neighbor
show ipv6 route

show ip nat translations
show ip nat statistics

ipconfig /renew
ping
traceroute
```

## What I Learned

This lab demonstrated a structured approach to enterprise network troubleshooting. I learned how to identify and resolve issues involving VLAN assignments, EtherChannel configuration, trunking, DHCP pools, OSPF routing, IPv6 routing, NAT translation, and WAN path selection. The lab emphasized using verification commands and systematic troubleshooting techniques to restore end-to-end connectivity.
