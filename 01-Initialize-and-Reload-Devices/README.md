# Initialize and Reload a Router and Switch

## Objective

Learn how to erase existing configurations and reload Cisco routers and switches to prepare devices for a new lab environment.

## Skills Practiced

- Accessing privileged EXEC mode
- Erasing startup configuration
- Deleting VLAN database
- Reloading Cisco devices
- Bypassing initial configuration dialog

## Commands Used

```cisco
enable
erase startup-config
reload
show flash
delete vlan.dat
```

## What I Learned

This lab demonstrated the proper procedure for resetting Cisco routers and switches to a clean default state before beginning a new networking lab.
