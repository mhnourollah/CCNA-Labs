# CCNA Labs

This repository contains hands-on Cisco CCNA lab exercises, Packet Tracer projects, and networking activities completed during my college studies.

The labs focus on practical networking concepts including routing, switching, network security, IPv4/IPv6 addressing, wireless networking, and troubleshooting. Each lab includes a summary of objectives, core configurations, verification steps, and key concepts learned.

## Topics Covered

- Router and Switch Configuration
- IPv4 Addressing and Subnetting
- VLANs and Inter-VLAN Routing
- DHCPv4 Configuration
- EtherChannel
- Port Security
- Static and Default Routing
- NAT and PAT
- OSPF Dynamic Routing
- Access Control Lists (ACLs)
- IPv6 Addressing and Connectivity
- Wireless Network Configuration
- SSH Remote Device Management
- Enterprise Network Troubleshooting
