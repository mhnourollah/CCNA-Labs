# CCNA Labs

This repository contains Cisco CCNA labs, Packet Tracer projects, configuration examples, and networking exercises completed during my college studies.

## Topics Covered

- Basic Device Configuration
- IPv4 Addressing and Subnetting
- VLANs
- Inter-VLAN Routing
- Static Routing
- OSPF
- Access Control Lists (ACLs)
- DHCP
- NAT
- Network Troubleshooting

## Tools Used

- Cisco Packet Tracer
- Cisco IOS CLI

## Purpose

This repository demonstrates practical networking skills developed through hands-on CCNA coursework and lab activities.
